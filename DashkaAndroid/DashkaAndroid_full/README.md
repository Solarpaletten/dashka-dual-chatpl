# 📱 Dashka Android — Sprint 1 Foundation

**Backend:** post-REC-001…005 (`https://dashka-chatpl.vercel.app/`)
**Scope:** text input → API translate → text output. RU ↔ PL.
**Decisions:** minSdk 26, PL-only, single active pane. No STT, no TTS, no Conversation Mode (later sprints).

## 🚀 First-time setup (one-time)

### 1. Open the project in Android Studio

```bash
# Use Android Studio Hedgehog (2023.1.1) or newer.
# Recommended: Iguana / Jellyfish / Koala / Ladybug.
File → Open → select DashkaAndroid/ directory
```

Android Studio will:
- create `local.properties` with `sdk.dir=...` automatically
- generate `gradle/wrapper/gradle-wrapper.jar` automatically on first Gradle sync
  (this binary is intentionally NOT included in the zip — it is regenerated by your IDE)

### 2. Configure the API token (REC-001)

The token is read at build time from `gradle.properties`. Two safe options:

**Option A — global property (recommended, never committed):**
```
# ~/.gradle/gradle.properties
DASHKA_API_TOKEN=<paste the value of DASHKA_API_TOKEN from Vercel here>
```

**Option B — command line:**
```bash
./gradlew assembleDebug -PDASHKA_API_TOKEN=<token>
```

If you leave it blank, the app will still build and run — but every API call will return
`401 Unauthorized` if the backend has its `DASHKA_API_TOKEN` env var set.

### 3. Build and run

```bash
./gradlew assembleDebug              # APK in app/build/outputs/apk/debug/
./gradlew installDebug               # install on connected device/emulator
```

Or click ▶ Run in Android Studio.

## 🔌 Backend smoke test (independent of Android)

Replace `<TOKEN>` with the value of `DASHKA_API_TOKEN`.

```bash
# Health
curl -i https://dashka-chatpl.vercel.app/api/health

# Translate
curl -i -X POST https://dashka-chatpl.vercel.app/api/translate \
  -H "Content-Type: application/json" \
  -H "X-Dashka-Token: <TOKEN>" \
  -d '{"text":"Привет, как дела","source_language":"RU","target_language":"PL"}'
```

If these work, the Android client should also work.
